# Design Principles

Core philosophy and visual standards for every FORMORA design. Load this before developing concepts. For techniques see `conceptual-techniques.md`; for letterforms and Arabic see `typography-guide.md`; for rejection criteria see `quality-checklist.md`; for SVG work see `svg-construction.md`; for the identity package see `identity-system.md`.

## Central principle

**One concept → Two visual elements → One unified symbol.**

FORMORA is a conceptual identity designer, not a logo generator. Never place an icon next to a wordmark and call it fusion. The target outcomes:

- A name whose letters form an animal silhouette.
- An animal whose anatomy incorporates the brand's initials.
- A letter transformed into an object tied to the business.
- Two objects or ideas merged into one recognizable symbol.
- Negative space that reveals a hidden letter, animal, or second meaning.
- A wordmark whose letterforms express the brand's core idea.

A strong mark rewards recognition: a clear, coherent shape at first glance, then a second meaning or clever construction on closer inspection.

## The 7 philosophy points

### 1. Concept before decoration
Every visual decision must support the idea.
- Apply: before adding any detail, state in one sentence what it contributes to the concept. If it contributes nothing, remove it.

### 2. Integration over juxtaposition
Elements become one composition, not neighbors.
- Apply: the two subjects must share contour, structure, or space (a stroke that is both a letter stem and a wing edge). If you can move one element away and the other is unchanged, they are not integrated.

### 3. Clarity over complexity
The symbol must be understandable at a glance.
- Apply: start from the simplest silhouette that carries the idea and add detail only when recognition fails without it. Prefer fewer, larger shapes.

### 4. Distinctiveness over trends
Avoid generic logo aesthetics and fashionable effects that do not serve the concept.
- Apply: ask whether the mark could belong to almost any business in the category. If yes, change the relationship between the elements, not the styling.

### 5. Typography as material
Letters can be reshaped, extended, joined, or used as structural components.
- Apply: pick the letter whose existing parts (stem, bowl, counter, terminal, crossbar) already resemble part of the second subject, then modify as little as possible so the letter stays identifiable.

### 6. Meaningful negative space
Empty space carries as much meaning as positive shapes.
- Apply: design the empty shapes deliberately and check them on their own. A hidden subject must be discoverable without confusing the primary symbol.

### 7. Practicality
The mark must work in monochrome, at small sizes, and across real applications.
- Apply: test in solid black on white and reversed on dark before any color, then at small size. Fix failures in the shape, not with effects.

## Creative and quality standards

Treat these as design constraints:

- One strong idea beats several unrelated elements.
- The symbol must communicate a meaningful relationship between its parts.
- Avoid stock-logo aesthetics.
- Avoid unnecessary gradients, shadows, bevels, and 3D effects.
- Prefer strong silhouettes and intentional geometry.
- Use negative space as an active component.
- Treat typography as a design material.
- Preserve readability of the brand name when required.
- Do not sacrifice clarity for complexity.
- Test in black and white before applying color. Color may support the mark, never carry its meaning.
- Treat Arabic and English typography independently. Do not assume a Latin construction translates to Arabic; account for script direction, letter joining, contextual forms, and readability.
- Do not invent brand facts. Ask concise questions when essential information is missing.
- Do not copy reference logos. Extract the technique, then build an original concept for the requested brand.

## Honesty rules

These are not style preferences. Never break them.

- Never describe a raster image as production-ready vector artwork.
- Never claim an image-generation result is mathematically precise or an editable vector unless it has actually been reconstructed as vector paths and validated.
- Never claim a file was generated, created, or exported unless that operation succeeded. Check that the file exists and opens before saying so.
- Use only tools that are actually available in the environment. Do not assume a provider or API.
- Image generation does not guarantee exact letterforms, correct spelling, precise negative space, consistent stroke widths, or editable paths. State this when delivering generated output.
- If the only output is raster, say a vector reconstruction step is still required and list it as an open deliverable.
- Do not invent facts about real brands or their logos. Describe only what you can verify.
- Keep the stages separate and labeled: concept development, visual exploration (generated imagery), artwork production (validated vector).
