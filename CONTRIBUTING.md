# Contributing to FORMORA

Thank you for helping. FORMORA is a set of instructions and templates, so most contributions are plain text.

## What is most useful
- **Native-reader checks** of Arabic (or any non-Latin) lettering in `examples/`.
- **Worked examples:** run the skill on a brief and share the concept brief and the SVG it produced.
- **Corrections** to the typography, colour or SVG guidance, with a source where one exists.
- **Template fixes:** a logo shape, palette or language that breaks `brand-presentation.html`.

## Ground rules
- Keep `SKILL.md` short. Detail belongs in `references/`, loaded only when needed.
- The skill's honesty rules are not negotiable: never call a raster image a vector, never claim a file exists
  unless it does, never present generated lettering as checked.
- No third-party logos, and no stock photos in the repository. Record photo sources in a `SOURCES.md`.
- Test a template change by filling it and printing it to PDF, then look at every page.

## How
1. Open an issue describing the change, or go straight to a pull request for small fixes.
2. Add a line to `CHANGELOG.md` under an "Unreleased" heading.
3. Say what you tested and what you did not.
